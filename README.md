# HEATWISE HySUPP Unmixing EOAP Processor

## Overview

This repository contains the **HEATWISE HySUPP-based supervised unmixing processor**.

The processor takes a CHIME-mimicked hyperspectral GeoTIFF and an endmember spectral library, runs **Fully Constrained Least Squares (FCLS)** supervised unmixing, and generates abundance maps and a top-1 classification map.

The processor is prepared as an EOAP-oriented component and can be executed as:

- a command-line Python application;
- a Dockerized processor;
- a CWL-described application package.

The current test case uses the Sepolia CHIME-mimicked product generated by the HEATWISE CHIME mimicking processor.

## Processing workflow

The processor performs the following operations:

1. Reads a CHIME-mimicked hyperspectral GeoTIFF.
2. Reads the image wavelength grid from a text file or raster band metadata.
3. Reads an endmember spectral library from CSV or XLSX.
4. Interpolates the endmember spectra to the image wavelength grid.
5. Selects valid spectral bands.
6. Converts the hyperspectral cube into a spectral matrix.
7. Runs supervised FCLS unmixing.
8. Writes an abundance stack as a Cloud Optimized GeoTIFF.
9. Writes a top-1 classification map as a Cloud Optimized GeoTIFF.
10. Writes class names, wavelengths used, and processing metadata.

---

## Inputs

### 1. CHIME-mimicked hyperspectral image

A multiband GeoTIFF containing the CHIME-mimicked hyperspectral product.

Example:

```text
data/Sepolia/Sepolia_CHIME_Thermopolis_v2_COG.tif
```

### 2. Endmember spectral library

A CSV or XLSX file containing one wavelength column and one column per endmember.

Expected structure:

```text
wl_um | asphalt_road | concrete | terracota | evergreen | metal
```

Example:

```text
data/Sepolia/endmembers_sepolia.xlsx
```

### 3. Wavelength text file

A text file containing the image wavelength centers, one wavelength per line.

Example:

```text
data/Sepolia/Sepolia_CHIME_Thermopolis_v2_wavelengths.txt
```

The wavelength values are expected in micrometers. If values are provided in nanometers, they are automatically converted to micrometers.

---

## Outputs

For a given output prefix, for example:

```text
Sepolia_FCLS
```

the processor generates:

```text
Sepolia_FCLS_abundance_stack_COG.tif
Sepolia_FCLS_classification_map_COG.tif
Sepolia_FCLS_class_names.json
Sepolia_FCLS_wavelengths_used_um.txt
Sepolia_FCLS_run_metadata.json
```

### Output description

The abundance stack contains one band per endmember/class. The values are continuous abundance fractions.

The classification map contains the top-1 class label obtained from the maximum abundance per pixel.

The class names JSON file stores the mapping between numerical labels and material names.

The wavelength file stores the spectral bands effectively used by the FCLS processor after spectral matching.

The metadata JSON file stores the processing parameters, input information, image dimensions, number of valid pixels, FCLS settings, and generated output filenames.

## Run locally with Python

Create and activate a Python virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the dependencies:

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Run the Sepolia test case:

```bash
mkdir -p results/sepolia

PYTHONPATH=src python processor.py \
  --input-image data/Sepolia/Sepolia_CHIME_Thermopolis_v2_COG.tif \
  --endmembers data/Sepolia/endmembers_sepolia.xlsx \
  --wavelengths-txt data/Sepolia/Sepolia_CHIME_Thermopolis_v2_wavelengths.txt \
  --output-dir results/sepolia \
  --output-prefix Sepolia_FCLS \
  --scale-factor 1.0 \
  --min-abundance 0.0 \
  --log-every 1000
```

## CWL execution

Validate the CWL file:

```bash
cwltool --validate heatwise_hysupp_unmixing.cwl
```

Run the Sepolia CWL example:

```bash
mkdir -p results_cwl/sepolia

cwltool \
  --outdir results_cwl/sepolia \
  heatwise_hysupp_unmixing.cwl \
  examples/job_sepolia.yml \
  2>&1 | tee results_cwl/sepolia/run_sepolia_cwl.log
```

Expected output files:

```text
Sepolia_FCLS_abundance_stack_COG.tif
Sepolia_FCLS_classification_map_COG.tif
Sepolia_FCLS_class_names.json
Sepolia_FCLS_wavelengths_used_um.txt
Sepolia_FCLS_run_metadata.json
run_sepolia_cwl.log
```

## Output check

A quick raster check can be performed with:

```bash
python - <<'PY'
import rasterio
import json

paths = [
    "results_cwl/sepolia/Sepolia_FCLS_abundance_stack_COG.tif",
    "results_cwl/sepolia/Sepolia_FCLS_classification_map_COG.tif",
]

for path in paths:
    with rasterio.open(path) as ds:
        print(path)
        print("  size:", ds.width, ds.height)
        print("  bands:", ds.count)
        print("  dtype:", ds.dtypes)
        print("  nodata:", ds.nodata)
        print("  crs:", ds.crs)
        print()

with open("results_cwl/sepolia/Sepolia_FCLS_class_names.json", "r", encoding="utf-8") as f:
    class_names = json.load(f)

print("Classes:")
for c in class_names["classes"]:
    print(f"  {c['label']}: {c['name']}")
PY
```

The Sepolia test case should generate:

```text
abundance stack:
  size: 87 x 110
  bands: 5
  dtype: float32
  nodata: -9999.0
  crs: EPSG:32634

classification map:
  size: 87 x 110
  bands: 1
  dtype: uint16
  nodata: 0
  crs: EPSG:32634
```

The five Sepolia classes are:

```text
1: asphalt_road
2: concrete
3: terracota
4: evergreen
5: metal
```

